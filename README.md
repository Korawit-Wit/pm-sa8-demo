# pm-sa8-demo

- `board.html` — PM SA8 Board (แผนบำรุงรักษาเตา F1–F9 ต.ค. 2026) ซิงค์สถานะ "เสร็จแล้ว" กับ Google Sheet ผ่าน Apps Script Web App
- `config.js` — ใส่ `API_URL` ของ Web App ที่นี่
- `index.html` — เวอร์ชันเดิม (PM SA8 Planner)

เปิดใช้งาน: Settings → Pages → Deploy from a branch → `main` / root
ลิงก์: https://korawit-wit.github.io/pm-sa8-demo/board.html
